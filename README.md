# Pinegrow, WordPress, and Codex workflow

A community guide to building custom WordPress sites with Pinegrow and Codex, plus a reusable project starter.

## Start here

1. Read the [human workflow guide](docs/workflow-guide.md).
2. Follow the [quick start](docs/quick-start.md) when beginning a site.
3. Copy the seven files in [`project-starter/`](project-starter/START-HERE.md) into a new project, then prepare its approved `PROJECT-SPEC.md`.

The guide describes one studio’s practical workflow and its limits; adapt it to your tools, ownership model, and project requirements. It does not grant access to Pinegrow, WordPress, MCP services, or specialist skills. Verify each connection and capability in your own environment.

## What is included

- Human-readable workflow and setup guidance
- Copy-ready new-project prompt and scoped task examples
- Seven reusable Codex project instruction and checklist files

The original Blueprint repository, historical archives, local site projects, and kickoff drafts are intentionally not included in this community package.
